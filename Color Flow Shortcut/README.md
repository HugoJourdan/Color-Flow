# COLOR FLOW SHORTCUT

This folder ships one script: **Jump To Next Unfinished (Color Flow)** — it opens the next glyph whose current-master layer colour is not the final visible workflow step.

To use it with a keyboard shortcut:

1. Download "Color Flow Shortcut" from Window > Plugin Manager.
2. Reload the scripts folder by pressing [ Option + Shift + Command + Y ].
3. In Glyphs > Settings > Shortcuts, search "Color Flow" and assign a shortcut to the item.

Note: the Color Flow palette itself also registers a native **Jump to next color glyph** command in *Glyphs > Settings > Shortcuts* (group "Color Flow"), so this script is only needed if you prefer the Scripts-menu version. Toggling workflow steps is done in the palette or via its context menu.
